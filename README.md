## How to run

1. Clone repo

2. Open repo in editor

3. Run

```
npm install
```

4. Create .env.local at root and add

```
JWT_SECRET=<Your jwt secret>
```

5. Run

```
npm run dev
```

6. Open in browserhttp://localhost:3000
